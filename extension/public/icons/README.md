# Service marks

These assets are bundled locally; the extension does not request icon files from third-party services at runtime. Marks retain the original artwork and colors.

- Google Drive: [Google's official Drive branding guide](https://developers.google.com/workspace/drive/api/guides/branding), [128px product mark](https://www.gstatic.com/images/branding/productlogos/drive_2026/v2/web-64dp/logo_drive_2026_color_2x_web_64dp.png).
- Jira, Confluence, and Atlassian: [Atlassian's official logo downloads](https://atlassian.design/foundations/logos). Isolated brand marks from `jira_app.zip`, `confluence_app.zip`, and `atlassian_logo.zip`.

Downloaded October 10, 2026. Brand marks belong to their respective owners; their published brand guidelines apply. `UiIcon.tsx` bundles interface glyphs from [Lucide](https://github.com/lucide-icons/lucide), with the upstream license in `LUCIDE-LICENSE.txt`. No additional package is required.
