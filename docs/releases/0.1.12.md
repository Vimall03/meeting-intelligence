# 0.1.12 — Zoom browser preview

- Adds meeting detection for the Zoom Web App in Chrome and Brave.
- Reuses existing audio capture for live assistance and optional recaps.
- Keeps Google Meet rooms and Zoom rooms separate, including during rejoining.
- Updates meeting guidance and the public Chrome Web Store link.

Zoom desktop calls are not supported. Connect Zoom computer audio before listening. Recaps are off by default; Jira tasks still require review and confirmation.

## Release gate

The downloadable package is a preview, separate from the currently published store version. A live two-person Zoom audio/reconnect/recap check remains required before Web Store submission. Automated and package checks do not replace this live verification.

## Checks completed

- Extension typecheck, 94 session/capture checks, and production build passed.
- All 161 backend checks passed, including authenticated Zoom streaming, recap completion, rejoining, and isolation.
- Production container and deployed room validation accept Zoom while preserving Google Meet compatibility.
- Narrow side-panel UI and desktop/mobile website previews checked.
- Source secret scan, release ZIP integrity, production endpoints, permissions, and published extension identity checked.

The browser UI fixture uses simulated accounts and media states; it does not prove real Zoom audio capture. No Web Store update has been submitted.
